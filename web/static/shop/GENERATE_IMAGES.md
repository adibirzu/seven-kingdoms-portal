# Nano Banana Image Generation Prompts — Seven Kingdoms Marketplace

Use these prompts with Nano Banana to generate product images for the shop.
Save each image as `.webp` (or `.png`) with the filename listed below.

**Style guidelines for ALL images:**
- Dark fantasy art style, moody lighting, dramatic shadows
- Color palette: deep blacks, dark blues, warm gold accents, muted reds
- Aspect ratio: 16:10 (wide), recommended 560x350px or 1120x700px
- No text/watermarks in the image
- Consistent medieval/high-fantasy aesthetic inspired by Game of Thrones
